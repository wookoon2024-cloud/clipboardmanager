# 📋 Clipboard Manager & Window Switcher

> **스마트 클립보드 히스토리 관리 및 고속 윈도우 작업공간 전환 도구**  
> Delphi VCL 네이티브 기반으로 개발되어 가볍고 빠른 반응 속도와 강력한 생산성 기능을 제공하는 Windows용 유틸리티입니다.

---

## ✨ 주요 핵심 기능 (Key Features)

### 1. 📑 스마트 클립보드 모니터링 & 히스토리
- **텍스트 및 이미지 자동 캡처**: 클립보드에 복사된 텍스트와 이미지 데이터를 실시간으로 감지하고 로컬 SQLite 데이터베이스에 안전하게 저장합니다.
- **중복 항목 필터링**: 중복 복사 방지 옵션 및 최대 히스토리 보관 개수 설정 지원.
- **독립형 대형 실시간 미리보기 (Live Preview)**: 마우스 오버 시 텍스트 전체 내용과 고해상도 이미지를 별도 팝업 창에서 시원하게 미리 볼 수 있습니다.
- **즐겨찾기(Favorites) 고정**: 자주 사용하는 텍스트나 문구를 상단에 고정하고 별도 관리/편집(`uFavEditForm`) 가능.

### 2. ⚡ 초고속 붙여넣기 (Quick Paste) & 뱃지 단축키
- 히스토리 팝업 호출 시 각 항목마다 할당되는 **숫자/알파벳 뱃지(1~10, A~Z)**를 키보드로 바로 눌러 즉시 붙여넣기.
- 마우스 클릭 없이 키보드만으로 과거 복사 기록을 빠르게 검색하고 작업 프로그램에 바로 입력 가능.

### 3. 🪟 윈도우 스위처 (Window Switcher) & 작업공간 프리셋
- **숫자 기반 창 전환**: 현재 실행 중인 윈도우들을 1~9번 슬롯에 매핑하여 전역 단축키로 원하는 창으로 번개처럼 전환.
- **깜빡임 없는 무지연 UI**: 고정 슬롯 캐싱 및 더블 버퍼링 기법을 적용하여 끊김 없는 화면 전환 경험 제공.
- **작업공간(Workspace) 프리셋 1~3 저장/복원**: 작업 중인 여러 프로그램 창의 배치를 슬롯별로 기억하여 원클릭으로 작업 환경 복원.
- **창 고정(Pin) & 빠른 종료**: 중요한 창을 상단에 고정하거나 불필요한 창을 즉시 종료.

### 4. 📌 데스크톱 퀵바 (QuickBar)
- 바탕화면 상단/가장자리에 상시 띄워둘 수 있는 컴팩트한 클립보드 바.
- 반투명도(Alpha) 조절 및 자동 숨김, 직관적인 툴팁 지원.

### 5. 🎨 완벽한 테마 및 UI 커스터마이징
- **다양한 프리셋**: 다크(Dark), 라이트(Light), 모던 플랫 등 다양한 스타일 프리셋 기본 제공.
- **세부 색상 커스텀**: 배경색, 선택 항목 강조색, 텍스트 색상, 카드 색상, 폰트 크기, 리스트 높이 등을 자유롭게 설정.

### 6. 🚀 시스템 트레이 & 윈도우 시작 시 자동 실행
- 백그라운드 시스템 트레이 상주로 리소스 점유율 최소화.
- Windows 시작 시 자동 실행 설정 지원.

## ⌨️ 기본 단축키 (Default Hotkeys)

| 기능 | 기본 단축키 | 설명 |
| :--- | :--- | :--- |
| **클립보드 히스토리 팝업** | `Ctrl + Shift + V` | 저장된 클립보드 목록을 띄우고 뱃지 키로 즉시 붙여넣기 |
| **데스크톱 퀵바 토글** | `Ctrl + Shift + Q` | 화면 상단 퀵바 보이기 / 숨기기 |
| **윈도우 스위처** | `Alt + Shift + W` | 실행 중인 윈도우 번호 슬롯(1~9) 팝업 호출 |
| **고속 붙여넣기 프리픽스** | `Ctrl + Win` | 단축키 조합을 통한 고속 붙여넣기 |
| **윈도우 전환 프리픽스** | `Alt` | Alt + 번호키로 빠른 창 전환 |

> 💡 *모든 단축키는 메인 설정 화면([단축키] 탭)에서 사용자가 원하는 키 조합으로 자유롭게 변경할 수 있습니다.*

## 🛠️ 빌드 및 실행 방법 (Build & Run)

### 요구 사항
- **Embarcadero Delphi 10.x / 11.x / 12.x** 이상 (VCL)
- **Windows 10 / 11** (32-bit & 64-bit 지원)

### 실행 방법
1. 저장소의 `ClipboardManager.zip`을 다운로드하여 압축을 푼 후 `ClipboardManager.exe`를 실행합니다.
2. 시스템 트레이에 아이콘이 상주하며, 단축키(`Ctrl+Shift+V` 또는 `Alt+Shift+W`)로 즉시 사용할 수 있습니다.
